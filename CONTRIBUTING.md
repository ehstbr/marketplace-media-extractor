# Contribuindo

Obrigado pelo interesse em contribuir com o Marketplace Media Extractor.

## Antes de abrir uma issue

- Confirme que o problema ocorre na versão mais recente.
- Informe a URL de um anúncio de exemplo quando isso for seguro e relevante.
- Inclua erros do console e o contexto da página.
- Para problemas de vídeo, inclua o relatório de diagnóstico quando disponível.

## Pull requests

- Evite dependências externas desnecessárias.
- Preserve o funcionamento local da extensão.
- Mantenha compatibilidade com Manifest V3.
- Não inclua código remoto executável.
- Rode as verificações de sintaxe antes de enviar.

## Segurança

Não publique credenciais, cookies, tokens ou dados privados em issues públicas.
