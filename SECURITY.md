# Segurança

Se encontrar uma vulnerabilidade que possa expor dados, permissões ou credenciais, evite publicar detalhes exploráveis em uma issue pública.

Quando disponível, prefira o recurso **Security Advisories** do GitHub para comunicar vulnerabilidades de forma privada aos mantenedores.

Nunca envie cookies, tokens, credenciais ou dados pessoais em relatórios públicos.
