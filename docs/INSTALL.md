# Instalação

## Chrome / Chromium

1. Baixe e extraia o pacote da extensão.
2. Abra `chrome://extensions`.
3. Ative **Modo do desenvolvedor**.
4. Clique em **Carregar sem compactação**.
5. Selecione a pasta que contém `manifest.json`.

## Atualização manual

Ao substituir os arquivos por uma versão mais nova, use **Recarregar** na página de extensões e recarregue as abas do Mercado Livre que já estavam abertas.

## Remoção

A extensão pode ser removida normalmente em `chrome://extensions`.
